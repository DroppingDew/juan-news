📦 selkies-project/selkies
📝 selkies：面向自托管、容器、Kubernetes 或云/HPC 的低延迟加速 Web 远程桌面串流平台
Selkies 是开源的 Linux 原生 GPU/CPU 加速低延迟远程桌面串流平台，由 Google 工程师发起，可自托管于容器、Kubernetes 或 Cloud/HPC 环境，宣称 Full HD 下 60fps 以上。默认走 WebSocket，可选 WebRTC；HTML5 客户端兼容 Chromium/Firefox/Safari，支持双向剪贴板、零拷贝视频渲染、手柄输入、麦克风与摄像头转发。适合 Agentic AI、机器人、自动驾驶等研究及云游戏场景。一条 docker run 即可启动桌面容器，也支持 pip install selkies、.deb/.rpm/.apk/AppImage 原生安装。
