📝 HAST-SEC：武汉光影流明科技有限公司 | 本地中文交互与连续角色运动 | 非商业早期研究版 | 寻求技术合作与融资
武汉光影流明科技发布的早期研究版虚拟角色交互系统（v0.1），基于约0.8B文本模型与小型运动模型，支持中文聊天、已支持动作的语义控制、连续角色运动、表情显示，并可实时查看最近15秒运动曲线与资源占用。可导入兼容VRM角色（100MB内），本机推理无需API密钥。需Node.js 22以上，克隆仓库后依次执行 npm ci、npm run setup（CPU）或 setup.ps1 -Cuda（NVIDIA显卡）安装，npm start 启动后访问 http://127.0.0.1:8769/language-lab 使用。非商业许可，商用需书面授权。
