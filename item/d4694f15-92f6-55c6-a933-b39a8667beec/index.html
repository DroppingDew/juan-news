📝 audacity：音频编辑器
Audacity 是一款知名的开源跨平台音频编辑器，采用 C++ 编写，基于 wxWidgets 构建图形界面，可在 Windows、macOS、Linux 等多平台运行。它支持音频录制、剪辑与多轨编辑等常见音频处理需求，是音频编辑领域应用最广泛的开源软件之一，项目在 GitHub 上获得超过 1.8 万 Star，采用 GPLv2 许可证开源。
