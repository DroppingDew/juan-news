📦 fooyin/fooyin
📝 fooyin：一个可定制的音乐播放器
fooyin 是一款可高度定制的桌面音乐播放器，支持 FLAC、MP3、Opus 等主流音频格式，以及 VGM、tracker 格式插件和压缩包内直接播放。提供灵活的库管理、播放列表、CUE 支持、无损与比特完美播放、ReplayGain、DSP 链、标签编辑与音频转换，并内置 FooScript 脚本语言实现自定义界面布局、查询与自动播放列表。支持歌词、Last.fm/Discord 集成、MPRIS 等。可通过 Flathub、Linux 发行版仓库或 GitHub Releases 安装，支持 Linux 与 Windows，macOS 支持即将推出，采用 GPLv3 许可。
https://github.com/fooyin/fooyin
📦 MeTerminator/MeT-Music_Desktop
📝 MeT-Music_Desktop：MeT-Music 桌面客户端，包含桌面歌词，后台播放，播放控制等功能。由 Electron 编写，支持多平台。
MeT-Music 桌面客户端由 Electron 编写，支持 Windows、macOS 与 Linux。提供桌面歌词（可置顶、锁定、自定义颜色字体）、后台播放与托盘管理、媒体键与全局快捷键控制、系统通知，以及极简设计的全屏播放器与动态背景。还提供可选的本地 HTTP/WebSocket 外部 API（默认 127.0.0.1:14558），供外部程序查询播放状态与控制播放。基于 Vue.js + Vite + Electron Forge 开发，使用 pnpm install 与 pnpm start 本地运行，pnpm dist 打包，MIT 许可。
https://github.com/MeTerminator/MeT-Music_Desktop
📦 SPlayer-Dev/SPlayer-Next
📝 SPlayer-Next：跨平台桌面音乐播放器，支持丰富歌词与多种音频格式
SPlayer-Next 是 SPlayer 的后继项目，一款跨平台桌面音乐播放器，基于 FFmpeg + Rust 原生模块构建高性能音频引擎。支持 MP3、FLAC、APE 等多种音频格式，提供 LRC/QRC/YRC/TTML 逐字歌词高亮与翻译，含桌面、灵动岛和任务栏歌词窗口；可连接 Subsonic/Navidrome/Jellyfin/Emby 多服务器，支持实时 FFT 频谱、元数据编辑、下载管理、SMTC/MPRIS/Now Playing 系统媒体集成与 Last.fm 记录。需 Node.js 22+、pnpm 10+ 与 Rust 工具链，pnpm dev 运行、pnpm build:win/mac/linux 打包，AGPL-3.0 许可。
https://github.com/SPlayer-Dev/SPlayer-Next
