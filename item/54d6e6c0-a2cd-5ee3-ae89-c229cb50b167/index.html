📝 MusicFree：插件化、定制化、无广告的免费音乐播放器
MusicFree 是一款基于 React Native 开发的插件化、定制化、无广告的免费音乐播放器，支持桌面端与移动端。它本身不内置任何音源，通过插件机制扩展音乐来源，用户可按需安装插件定制功能，界面简洁纯净，在 GitHub 上已获得超过 2.7 万 star。适合追求干净、可定制听歌体验的用户。
