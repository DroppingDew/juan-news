📝 Screenbox：基于 LibVLC 的通用 Windows 平台媒体播放器
Screenbox 是一款面向通用 Windows 平台（UWP）的媒体播放器，基于 LibVLC 媒体引擎构建，采用 C# / .NET 开发。它借助 VLC 强大的解码能力，为 Windows 用户提供现代化的本地音视频播放体验，支持播放多种格式的多媒体文件。项目在 GitHub 上获得约 4.5k Star，是 Windows 平台上开源媒体播放器的一个热门选择。
