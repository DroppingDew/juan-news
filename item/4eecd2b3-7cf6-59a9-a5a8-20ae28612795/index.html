📝 rea：用智能体逆向工程一切，从应用行为到原生二进制。
REA 是一个面向 AI 编码智能体的逆向工程 MCP 服务器，可让 Agent 在无源码情况下分析原生二进制、JavaScript/Electron 应用、.NET 程序集、Android APK、网站、网络抓包与固件等，返回伪代码、汇编、模块导入、IPC 关系等结果并附证据。安装方式：运行 npx rea-agents setup，选择并注册到 Claude Code、Codex、Cursor、Gemini CLI 等智能体；也可通过 npm install --global rea-agents 安装 CLI 在终端直接使用。原生分析可复用已有的 Hopper 或 Ghidra，静态 JS 分析无需额外引擎。
