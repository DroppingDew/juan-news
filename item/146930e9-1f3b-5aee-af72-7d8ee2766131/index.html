📝 flux-reader：一款为 Windows 11 设计的本地 RSS 和 Atom 阅读器。
flux-reader 是一款专为 Windows 11 设计的本地 RSS 与 Atom 订阅阅读器，采用 C# 开发，基于 WinUI 3 构建原生界面，数据完全保存在本地，适合希望在桌面端离线管理信息流的用户。
