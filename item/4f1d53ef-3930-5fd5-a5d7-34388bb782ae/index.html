📦 mediago-dev/mediago
📝 mediago：跨平台视频下载器——嗅探并抓取 m3u8/HLS 流，支持 Bilibili、YouTube 等。提供桌面版 + Docker + 🦞。
MediaGo 是一款内置视频嗅探功能的跨平台下载器，指向网页即可挑选并保存视频，无需抓包或浏览器扩展配置。核心能力包括：Chrome/Edge 浏览器扩展一键嗅探并发送到 MediaGo；基于 yt-dlp 支持 YouTube、Bilibili、Twitter/X 等 1000+ 站点；下载后可在应用内直接转换格式与画质；提供完整 HTTP API 供脚本与自动化工具调用；支持通过 OpenClaw Skill 让 AI 编码助手代为下载（npx clawhub@latest install mediago）。支持 Windows/macOS/Linux 桌面版安装，也可 Docker 一行命令部署（docker run -d --name mediago -p 8899:8899 -v /path/to/mediago:/app/mediago caorushizi/mediago:3.5.0），提供 amd64 与 arm64 镜像，桌面版还支持局域网内手机访问 Web UI。
