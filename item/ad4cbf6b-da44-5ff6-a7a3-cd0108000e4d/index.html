📝 lx-music-mobile：一个基于 React native 开发的音乐软件
LX Music 移动版是一款基于 React Native 和 Redux 开发的开源音乐播放软件，支持 Android 5 及以上系统，暂无 iOS 和 HarmonyOS NEXT 支持计划。软件本身不含音频获取能力，在线数据来自官方平台公开服务器的拉取与合并，音频播放依赖用户在设置中配置的“自定义源”。从 v1.0.0 起还提供独立的数据同步服务，可部署到自有服务器实现多端同步列表。项目基于 Apache License 2.0 发行，仅供技术学习交流，要求用户 24 小时内清除版权数据并支持正版。
