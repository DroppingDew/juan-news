📦 KDE/kdenlive
📝 kdenlive：基于 MLT Framework 和 KDE Frameworks 的免费开源视频编辑器
Kdenlive 是 KDE 旗下免费开源的视频编辑软件，基于 MLT Framework 和 KDE Frameworks 构建，使用 C++ 开发。它为用户提供专业的非线性视频剪辑能力，涵盖多轨时间线编辑、视频与音频素材处理等常见剪辑需求，适合从入门到进阶的各类视频创作场景。项目在 GitHub 上获得超过 5800 颗星，社区活跃，用户可自由下载使用并参与贡献。
