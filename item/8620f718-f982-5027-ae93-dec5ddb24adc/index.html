📝 JuanNiang-Neo：复活吧卷娘
JuanNiang-Neo 是基于 OneBot11 协议的 QQ 聊天 Agent（红岩网校吉祥物卷娘），Go 编写，基于 Eino ADK 构建 ChatModelAgent。核心能力：ReAct 循环内工具调用、每聊天区最多 8 个 Agent 并发、四层记忆体系（短期/长期/技能/会话）、相关性回复优化将热聊判断开销降至约 1/10；内置 Lua 插件系统与插件商店、知识库、图床、表情包库、摸鱼人日历、积木式定时消息，并配 Vue 3 Web 管理面板。支持 Provider/MCP/Tool/Skill 多模块组合，通过 Docker Compose 一键部署（含 Postgres + Redis）。
