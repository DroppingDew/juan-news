📦 OpenBMB/VoxCPM
📝 VoxCPM：VoxCPM2：无分词器 TTS，支持多语言语音生成、创意声音设计与逼真克隆
OpenBMB 开源的无分词器 TTS 系统，采用端到端扩散自回归架构直接生成连续语音表征。VoxCPM2 为 2B 参数模型，基于 MiniCPM-4 骨干，用超 200 万小时多语言语音数据训练，支持 30 种语言及多种中文方言；提供自然语言描述的声音设计、可控音色克隆、保真极限克隆，48kHz 录音室级输出。RTF 低至约 0.3（RTX 4090），经 Nano-vLLM/vLLM-Omni 加速可达约 0.13。Apache-2.0 许可，pip install voxcpm 即用，支持流式合成、llama.cpp-omni 端侧推理，附 HuggingFace Demo 与技术报告。
