ImageGlass 是一款快速、现代的开源图片查看器，支持 90 多种图片格式，包括 WEBP、GIF、SVG、AVIF、JPEG XL（JXL）、HEIC 及 RAW 等格式，可流畅浏览各类图片。基于 C#/.NET 开发（新版本采用 Avalonia UI），支持 Windows、macOS 和 Linux 三大平台。项目在 GitHub 上获得超过 1.4 万 star，适合需要查看多种现代图片格式的用户替代系统自带看图工具。
