📝 lx-music-desktop：一个基于 Electron 的音乐软件
洛雪音乐（lx-music-desktop）是一款基于 Electron + Vue 开发的免费开源桌面音乐软件，使用 TypeScript 编写，支持 Windows、macOS 等平台。它以简洁的界面和丰富的音乐播放功能著称，在 GitHub 上获得超过 5.4 万 star，是最受欢迎的开源音乐播放器项目之一。
