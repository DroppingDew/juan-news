📝 folia-major：专注于绚丽的歌词动画效果的本地音乐/navidrome/第三方多平台在线音乐播放器
folia-major 是一款专注于绚丽歌词动画效果的本地音乐播放器，同时支持作为 Navidrome 客户端以及接入第三方多平台在线音乐（如网易云音乐）使用。项目基于 React 与 TypeScript 开发，支持 PWA 安装，可部署到 Vercel，并结合 AI 相关能力提升听歌体验，适合追求视觉化歌词展示效果的音乐爱好者。
