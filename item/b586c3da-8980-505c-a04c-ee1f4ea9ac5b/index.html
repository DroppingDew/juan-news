📦 cwuom/NeriPlayer
📝 NeriPlayer：一个把多源在线播放、本地管理、歌词体验和自建同步做进原生 Android 的音频播放器 🎵
NeriPlayer（音理音理!）是基于 Jetpack Compose + Media3 的原生 Android 音频播放器，支持 Android 9 及以上。它整合网易云音乐、Bilibili 与 YouTube Music 的在线播放（依赖用户自身账号授权），提供本地下载、缓存、歌单管理，并可通过 GitHub 或 WebDAV 自建同步歌单与播放统计。特色包括逐字/逐行歌词与翻译音译显示、GLSL 流体音频响应背景、桌面小组件、悬浮歌词、一起听功能、USB 独占输出与均衡器。数据本地优先、去中心化同步，注重隐私与账号安全，项目持续迭代中。
