📦 djkcyl/farwing
📝 farwing：Farwing — 远方，随手可及。用 Rust 编写的远程桌面与串流项目，让工作、游戏和多人共享用上同一套工具。
Farwing（远方）是一个用 Rust 编写的远程桌面与串流项目，基于 WebRTC 实现远程控制、屏幕共享、远程协助与游戏串流，支持 Windows 平台并可自托管部署，旨在让工作、游戏和多人共享场景使用同一套工具，实现"远方，随手可及"。
