📝 OpenCut：开源的 CapCut 替代品
OpenCut 是一款免费开源的视频编辑器，支持网页、桌面和移动端，定位为剪映（CapCut）的开源替代品，采用 TypeScript 开发、MIT 协议。项目正在从零重写，规划包括 Editor API、插件优先架构、基于 Rust 内核的跨端统一代码库、面向 AI 智能体的 MCP server、支持自动化与批量渲染的 Headless 模式以及编辑器内脚本功能。当前可用的经典版本托管于 opencut-app/opencut-classic，在线服务运行于 opencut.app，重写版预览在 new.opencut.app。开发者可使用 proto 与 moon 运行 web:dev、api:dev、desktop:dev 进行本地开发。
