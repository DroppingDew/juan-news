Niko1221/Strata

📦 Niko1221/Strata
📝 Strata：在任意消费级硬件上运行 Qwen3.8-Flash-Next：Windows/Linux 一键安装，Strata 推理引擎，本地 OpenAI/Anthropic API，可选图像输入。
Strata 是一个免费开源的本地推理引擎（C++），让普通游戏 PC 一键运行 1250 亿参数的 Qwen3.8-Flash-Next 大模型，支持 NVIDIA（RTX 20~50 系）与 AMD（RX 7900 XT 等）显卡，需 12GB 以上显存、32GB 以上内存。它把模型封装成本地 OpenAI/Anthropic 兼容 API（http://127.0.0.1:8080/v1），可接入 Claude Code、Codex CLI 等编码工具，并提供 MCP server 供 AI 助手安装管理。支持聊天、写代码、读图、多档思考强度、多 GPU 分担，RTX 5070 上 Q2_0 量化可达 94 tokens/s 输出。Windows 双击 START-HERE.bat、Linux 运行 ./setup.sh 即可安装。
