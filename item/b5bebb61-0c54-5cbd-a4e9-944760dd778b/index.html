📦 lizrice/learning-ebpf
📝 learning-ebpf：O'Reilly 出版的《Learning eBPF》配套仓库，提供书中示例所需的虚拟机配置及更多资源
这是 O'Reilly 图书《Learning eBPF》的官方配套仓库，包含书中各章节讨论的 eBPF 示例程序，涵盖 BCC 基础示例、C 语言 XDP 程序、bpf() 系统调用、CO-RE 与 libbpf、eBPF 验证器、网络与安全（LSM）等主题。仓库提供 Lima 虚拟机配置文件，预装构建所需依赖，也给出了 libbpf 与 bpftool 的源码构建方法。示例已在 Ubuntu 22.04（5.15 内核）上测试，运行多数示例需 root 权限，可通过 trace_pipe 或 bpftool 查看跟踪输出。
