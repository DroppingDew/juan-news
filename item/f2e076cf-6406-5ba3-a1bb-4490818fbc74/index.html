📦 qier222/YesPlayMusic
📝 YesPlayMusic：高颜值的第三方网易云播放器，支持 Windows / macOS / Linux :electron:
基于 Vue.js 全家桶开发的第三方网易云音乐播放器，提供网页版和 Electron 桌面客户端（支持 Windows/macOS/Linux）。支持网易云账号登录（扫码/手机/邮箱）、MV 播放、歌词显示、私人 FM、每日推荐、音乐云盘、Last.fm Scrobble，并通过 UnblockNeteaseMusic 自动替换变灰歌曲链接（网页版不支持）。可通过 Homebrew（brew install --cask yesplaymusic）或 Scoop 安装，也可部署到 Vercel、自有服务器、Docker 或 Replit 使用。
