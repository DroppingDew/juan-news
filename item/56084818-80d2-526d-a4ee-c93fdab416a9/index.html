📝 JuanNiang-Docs：JuanNiang-Neo 文档站
基于 Docusaurus 构建的 JuanNiang-Neo 项目文档站点，涵盖入门、部署调试、二次开发（架构、Web API、LLM Provider 适配、Webhook 与 CronJob）与插件开发四大章节。支持暗色模式、Mermaid 图表渲染、基于 @easyops-cn/docusaurus-search-local 的中文分词本地全文搜索。可通过 npm install && npm start 本地开发，构建产物可部署到 GitHub Pages/Vercel/Netlify，仓库自带多阶段构建 Dockerfile（Node 构建 + nginx 托管），docker build 后运行于 8080 端口并内置 /healthz 健康检查。
